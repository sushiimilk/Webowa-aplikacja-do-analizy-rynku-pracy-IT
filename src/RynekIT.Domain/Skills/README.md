# Domain/Skills – słownik umiejętności

`Skill.cs` to jedna umiejętność / technologia, np. `Python`, `SQL`, `Docker`.

Ten sam słownik jest używany przez **oferty** (czego oferta wymaga) i przez **CV** (co umie kandydat). Dzięki temu porównanie CV z ofertą to po prostu sprawdzenie, które `SkillId` występują w obu miejscach.

Nazwa umiejętności jest unikalna – nie może być dwóch „Python”.
