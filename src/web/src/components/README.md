# web/src/components – wspólne komponenty UI

Komponenty, które **nie wiedzą nic o ofertach, CV ani użytkownikach** – tylko wyglądają i reagują. Np. przycisk, tabela, spinner ładowania, okno dialogowe.

Planowany podfolder `ui/` na podstawowe klocki: `Button.tsx`, `Spinner.tsx`, `ErrorMessage.tsx`.

**Kiedy coś tu przenieść:** gdy ten sam komponent jest potrzebny w co najmniej dwóch funkcjach z `features/`.
