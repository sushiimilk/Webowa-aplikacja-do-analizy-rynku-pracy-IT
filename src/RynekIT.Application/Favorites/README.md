# Application/Favorites – ulubione oferty (do zrobienia)

Tu trafią przypadki użycia, np.:

- `AddFavorite/` – zapisanie oferty jako ulubionej
- `RemoveFavorite/` – usunięcie z ulubionych
- `GetFavorites/` – lista ulubionych ofert zalogowanego użytkownika

Wymagają zalogowanego użytkownika (ASP.NET Identity w Infrastructure).
