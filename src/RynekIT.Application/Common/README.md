# Application/Common – klasy wspólne

Małe klasy, z których korzysta wiele przypadków użycia.

| Plik | Co to |
|---|---|
| `PagedResult.cs` | Wynik z podziałem na strony: lista elementów + numer strony + łączna liczba wyników |

Wrzucaj tu coś dopiero, gdy jest używane w **co najmniej dwóch** miejscach. Jeśli coś dotyczy tylko jednego przypadku użycia – trzymaj to w jego folderze.
